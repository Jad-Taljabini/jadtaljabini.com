# Hospitality character

Generated with the built-in ImageGen tool, using Jad's supplied JPG portrait as the identity reference. Original photographs are not included in the public website. The generated RGBA atlas has a transparent background and is consumed directly by CSS (four columns, two rows).

## Prompt

Use case: stylized-concept. Asset type: transparent PNG sprite atlas for a personal website animation. Reference image is ONLY identity reference for Jad, the young adult man. Preserve his recognizable facial proportions, dark curly hair, thick eyebrows, long straight nose, light olive skin, faint chin beard. Create a polished hand-painted editorial 2D character, natural proportions with a slightly enlarged head for recognition at small scale, subtle shading, clean edges, not pixel art or toy 3D. Exact atlas layout: FOUR equal-width columns and TWO equal-height rows, landscape canvas 1536x1024. Eight isolated full-body figures, one perfectly centered within each cell, transparent space around all figures, no overlaps, identical scale and feet baseline within each cell, head near 10% cell height and shoes near 92%. No grid lines, labels, numbers, scenery or text. Jad wears an ivory short-sleeve tee, dark olive trousers and white sneakers. Top row, left to right: FOUR consecutive distinct frames of Jad walking to the RIGHT, three-quarter right-facing face sufficiently visible; alternating leg and arm strides of a walk cycle. Bottom row col1: same Jad standing facing right, right arm outstretched horizontally offering a tiny brass key; bottom row col2: same Jad standing smiling and waving towards right; bottom row col3: a DIFFERENT adult guest, smiling woman with straight chestnut hair, muted terracotta blouse, cream trousers, simple sneakers, facing LEFT, hand outstretched to receive a key; bottom row col4: same guest walking to RIGHT, smiling, holding key. All eight figures are fully visible head to toe, no cropping, no background, no floor, no shadows beyond contact-level soft detail. Jad must look like the referenced person, not a generic man.

## Animation

Top row: four walking poses. Bottom row: Jad handing over a key, Jad waving, guest receiving the key, guest walking toward the door. CSS controls position and frame selection; JavaScript controls the sequence and navigation. The ordinary link remains functional without JavaScript. Reduced-motion preferences bypass the sequence, the skip button opens the page immediately, and Escape cancels and restores focus.
